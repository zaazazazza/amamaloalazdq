STOCK - EMOJIS PERSONNALISES

La commande .stock détecte automatiquement les emojis personnalisés du serveur.

Correspondance :
  stock/epicgames.txt  -> emoji Discord nommé "epicgames"
  stock/snapchat.txt   -> emoji Discord nommé "snapchat"
  stock/netflix.txt    -> emoji Discord nommé "netflix"

Le nom de l’emoji doit correspondre au nom du fichier .txt (sans .txt).
Si aucun emoji correspondant n’existe, le bot affiche 📦 à la place.
